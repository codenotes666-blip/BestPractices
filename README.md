# BestPractices

Greg's practices and tooling for every workspace, on every machine.

**Agents: start with [greg_best_practices.md](greg_best_practices.md).**

- `adopt.py` - installs the kit into a repo (no login needed).
- `kit/` - generic scripts (`wake.py`, `wake_sync.py`, `hibernate.py`, `notes_index.py`),
  the SessionStart hook, templates (`greg.md`, `AGENTS.md`, `SESSION_STATE.md`) and the
  VS Code user-level pointer.
- `tests/` - `python -m pytest tests -q`.

Public repo: no personal, financial or secret information.
